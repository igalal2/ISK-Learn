💡القواعد اللغوية: الإشارة للمفرد والجمع (This is / These are)

1. للمفرد (قطعة واحدة): This is a...

نستخدم This is a / an مع الملابس المكونة من قطعة مفردة:

  • This is a T-shirt. (هذا تي شيرت)
  • This is a cap. (هذه قبعة / كاب)
  • This is a yellow dress. (هذا فستان أصفر)

2. للجمع والأشياء المزدوجة: These are...

الملابس التي تتكون من جزأين أو فردتين (مثل الحذاء، الشراب، البنطلون، الشورت) تعامل معاملة الجمع في الإنجليزية وتأخذ These are بدون a:

  • These are socks. (هذه جوارب)
  • These are shoes. (هذا حذاء - زوج)
  • These are pants. (هذا بنطلون)

📝اختبار الوحدة التفاعلي (Interactive Unit Quiz) مع الحل النموذجي
1. نختار مع كلمة socks (الجوارب):
A) These are socks. 🧦
B) This is a socks.
الإجابة الصحيحة: A) These are socks. لأن socks جمع (فردتان) وتأخذ These are بدون a.
2. ما الحرف الأول في اسم الصديقة Dina وحيوان donkey؟
A) Letter Dd 🫏
B) Letter Mm 🥛
الإجابة الصحيحة: A) Letter Dd بصوت /d/ مثل donkey, Dina, doll.
3. كلمة mug (كوب المشروب) تبدأ بحرف:
A) Letter Mm ☕
B) Letter Gg 🎸
الإجابة الصحيحة: A) Letter Mm مثل mug, mommy, Mazen.
4. أي مما يلي يمثل قطعة واحدة ونستخدم معها This is a...؟
A) cap (قبعة) 🧢
B) pants (بنطلون) 👖
الإجابة الصحيحة: A) cap (قبعة) لأنها مفرد فنقول This is a cap.
5. عندما نريد العزف على الجيتار نقول: I play the...
A) guitar 🎸
B) grass 🌱
الإجابة الصحيحة: A) guitar وتبدأ بحرف Gg.
