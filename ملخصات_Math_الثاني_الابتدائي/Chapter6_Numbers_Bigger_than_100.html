🔢3-Digit Numbers Mastery (الأعداد الأكبر من 100)

Place Value (القيمة المكانية): Hundreds, Tens, Ones:

In number 378:
• 3 is in Hundreds place ➔ Value = 300.
• 7 is in Tens place ➔ Value = 70.
• 8 is in Ones place ➔ Value = 8.
• Expanded Form (الصيغة الممتدة): 378 = 300 + 70 + 8.

Comparing 3-Digit Numbers (مقارنة الأعداد):

1. First compare Hundreds (المئات أولاً).
2. If Hundreds are equal, compare Tens (العشرات).
3. If Tens are equal, compare Ones (الآحاد).
Example from book: 378 < 397 because hundreds are both 3, but 7 tens < 9 tens!
