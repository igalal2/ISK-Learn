➕Vertical Addition Concepts (الجمع الرأسي)

Rule 1: Align Ones and Tens (محاذاة الآحاد والعشرات):

Always add Ones first (الآحاد أولاً), then add Tens (العشرات ثانياً).

2 3
+ 1 2
-----
3 5 (3+2=5 ones, 2+1=3 tens)

Rule 2: Regrouping / Carrying over (الجمع بإعادة التسمية):

When the sum of ones is 10 or more, write the ones digit below and carry 1 ten to the tens column!
Example: 27 + 15 ➔ 7 + 5 = 12 (write 2, carry 1) ➔ 1 + 2 + 1 = 4 tens ➔ Result: 42.

✅ الجزء الثالث: نموذج الحل النموذجي المفصل (Part 3: Explanatory Model Answers)

إجابات نموذجية مدعمة بسبب اختيار الحل لتسهيل المراجعة على ولي الأمر والمعلم

✅ نموذج إجابة الجمع الرأسي:
  • ✓ 45 + 23 = 68 (5+3=8 ones, 4+2=6 tens).
  • ✓ 61 + 37 = 98 (1+7=8 ones, 6+3=9 tens).
  • ✓ 38 + 25 = 63 (8+5=13 ➔ write 3, carry 1 ➔ 1+3+2=6 tens).
  • ✓ 49 + 16 = 65 (9+6=15 ➔ write 5, carry 1 ➔ 1+4+1=6 tens).
